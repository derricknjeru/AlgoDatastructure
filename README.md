# AlgoDatastructureInKotlin

Data structures and algorithms implemented in Kotlin.

## Contents

- **adventofcode2024** — Solutions for [Advent of Code 2024](https://adventofcode.com/2024) (Days 1–2)
- **grind75** — Solutions to problems from the [Grind 75](https://www.techinterviewhandbook.org/grind75) interview-prep list (arrays, stack implementation)
- **fundamentals** — Kotlin language practice:
  - Classes (data classes, enums, generics, scope functions, singletons, etc.)
  - Collections (arrays, lists, maps, sets, high-order functions)
  - Coroutines (synchronous vs asynchronous code)
  - General syntax and practice apps

## Requirements

- JDK 17
- Gradle 8.14+

## Build

```sh
./gradlew build
```
